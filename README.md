Подготовлено 10 тестов, распределенных по группам api ручек на 2 файла:

1. Тесты (4 теста) на проверку создания курьера через ручку /api/v1/courier, файл test_courier.py, класс для ручки TestCreateCourier:
- тест на возможность создания курьера, возврата кода ответа 201 и {"ok":true}: test_success_create_courier.
- тест на невозможность создания двух курьеров с одинаковыми логином, паролем и именем: test_unsuccess_create_two_identical_couriers. В рамках тестирования обанружен баг - возвращаемый ответ "Этот логин уже используется. Попробуйте другой." не соответсвтует из тестовой дкоументации "Этот логин уже используется".
- тест на невозможность создания курьера без передачи в ручку обязательного поля (Логина, пароля или имени): test_unsuccess_create_couriers_without_required_param.  В рамках тестирования обнаружен баг - курьера возможно зарегестировать без передачи парамтра firstName (в документации является обязательным).
- тест возврата ошибки при создании курьера с логином, который уже зарегестрирован: test_unsuccess_create_courier_with_identical_logins  В рамках тестирования обанружен баг - возвращаемый ответ "Этот логин уже используется. Попробуйте другой." не соответсвтует из тестовой дкоументации "Этот логин уже используется".
2. Тесты (4 теста) на проверку авторизации курьера в системе через ручку /api/v1/courier/login, файл test_courier.py, класс для ручки TestLoginCourier:
- тест на возможность авторизации курьера в системе при передаче всех обязательных полей и возвратом id курьера: test_success_login_courier.
- тест на невозможность авторизации курьера без передачи в ручку обязательного поля (логина или пароля): test_unsuccess_login_courier_without_required_param.
- тест возврата ошибки при неправильно переданном в ручку логина или пароля: test_unsuccess_login_courier_with_mistake_in_fieldю
- тест возврата ошибки при попытке авторизации под несуществующим пользователем: test_unsuccess_login_courier_with_unregistred_data.
3. Тест на проверку создания заказа через ручку POST /api/v1/orders с выбором одного из двух цветов, выбором 2-х цветов одновременно и без выбора цвета, файл test_order, класс для ручки TestCreateOrder: test_success_select_colour_in_create_order.
4. Тест на проверку получения списка заказов через ручку GET /api/v1/orders, файл test_order, класс для ручки TestGetListOfOrder: TestGetListOfOrder.

Файл conftest.py - фикстура создания тестовых данных для регистрации курьера в системе

Файл data.py - статичные данные для полей курьера и заказа

Файл cur.py - адреса тестируемых ручек

Файл helper.py - генерация данных для создания курьера и методы для их корректировки

Файл courier_api.py - методы обращения к тестируемым ручкам

Файл requirements.txt - список всех установленных пакетов и их точных версий
